# Trrack

**R**eproducible **track**ing — a TypeScript library for action-based provenance tracking in web applications.

## Packages

- [`@trrack/core`](./packages/core) — Core provenance tracking library

## Development

```bash
pnpm install
pnpm build
pnpm test
pnpm lint
pnpm typecheck
```
